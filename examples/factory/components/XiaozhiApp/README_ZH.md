# AIChats 语音对话

[English](README.md) | [简体中文](README_ZH.md)

## 功能

从出厂桌面打开小智语音对话，屏幕显示简洁笑脸和连接状态。

## 硬件需求

开发板、已连接的扬声器及可上网的 Wi-Fi，使用板载麦克风。

## 怎么运行

启动[出厂桌面](../../README_ZH.md)，在 Settings 联网后打开 **AIChats**；首次使用按屏幕提示激活，再说“你好小智”开始；也可以点击笑脸开始或停止对话。

## 预期现象

屏幕显示静态笑脸、当前状态和底部字幕，扬声器播放回答。底部依次显示你的识别文字和小智的回复，较长句子可以在文字区域上下滑动查看。可以说“把音量调到80”或“把亮度调到50”来调节音量和亮度；从底部中间上滑返回桌面。

## 常见问题

- **无法连接或激活：**确认 Wi-Fi 可以上网，按屏幕提示及[配网说明](../../USER_GUIDE_ZH.md#连接-wi-fi)操作。
- **回复没有声音：**检查扬声器及 Settings 音量；从源码烧录时使用 `idf.py flash` 烧录所需语音模型，不要只烧录应用 BIN。
